# Fundamentos de Desarrollo Web

## Resumen del curso

En este curso crearás **Fuera de Clase**, una página de recomendaciones de música, juegos y actividades creativas. Comenzarás con un título y un párrafo en CodePen. A lo largo de ocho lecciones añadirás imágenes, enlaces y tarjetas, les darás estilo con CSS y comprobarás que la página se pueda leer tanto en una computadora como en un celular.

- **Duración total estimada:** 63 minutos y 22 segundos
- **Público objetivo:** estudiantes de secundaria de 12 a 17 años que comienzan a programar.
- **Prerrequisitos:** ninguno.
- **Herramientas necesarias:** navegador web y CodePen clásico.
- **Repositorio del código fuente:** https://github.com/SirEthan04/webdev-course-proxy

## Secuencia de las lecciones

### Lección 1. Tu primera página: de mirar a crear (8:19 min)

- **Descripción:** Abre un Pen y escribe el nombre del club y su presentación. Al editar el encabezado en HTML y renombrar el Pen por separado, comprueba qué cambio ve quien visita la página.
- **Enlace:** https://youtu.be/cO6w9RbEwoI
- **Consejos clave:** HTML para la estructura, CSS para la presentación, paneles de CodePen, vista previa, `<h1>` y `<p>`.
- **Práctica:** https://codepen.io/editor/Mateo-CB/pen/01a1c29d-b8e6-7f93-aa5e-cb68b2fa8b29

### Lección 2. Títulos y listas: que se entienda lo que cuentas (7:39 min)

- **Descripción:** Organiza tres recomendaciones y explica cómo compartir una nueva. Elige encabezados para orientar al lector, viñetas para las opciones y números para los pasos que siguen un orden.
- **Enlace:** https://youtu.be/XG06eIHPXu8
- **Consejos clave:** Jerarquía de `<h1>`, `<h2>` y `<h3>`; párrafos; listas `<ul>` y `<ol>` con elementos `<li>`.
- **Práctica:** https://codepen.io/editor/Mateo-CB/pen/01a1c417-ffdf-7042-a7d9-3096e95dd154

### Lección 3. Imágenes y enlaces: que la página tenga algo que mostrar (7:51 min)

- **Descripción:** Incorpora una imagen con una descripción útil y crea un enlace que salte a las recomendaciones. Luego corrige una dirección de imagen incompleta y un destino interno que no coincide.
- **Enlace:** https://youtu.be/ZDL5Bc_GaPQ
- **Consejos clave:** `<img>`, `src`, `alt`, `<a>`, `href` y destinos internos con `id`.
- **Práctica:** https://codepen.io/editor/Mateo-CB/pen/01a1c5fb-08ee-7fa1-99b1-848aa29cbe60

### Lección 4. Una estructura que tenga sentido (8:23 min)

- **Descripción:** Distribuye el contenido del club entre cabecera, navegación, sección principal y pie. Convierte las recomendaciones en tres artículos que comparten una clase.
- **Enlace:** https://youtu.be/hjKoN9psNiU
- **Consejos clave:** `<header>`, `<nav>`, `<main>`, `<section>`, `<article>` y `<footer>`; clases compartidas e identificadores únicos.
- **Práctica:** https://codepen.io/editor/Mateo-CB/pen/01a1c647-4d76-7abe-a7b1-9d0418d08d6e

### Lección 5. CSS: ahora sí, que tenga personalidad (7:42 min)

- **Descripción:** Aplica color, fondo y tipografía desde el panel CSS. Comprueba qué tarjetas cambian al modificar una regla y compara dos combinaciones de color según su legibilidad.
- **Enlace:** https://youtu.be/rh6-ur3CfVU
- **Consejos clave:** Selectores de elemento y clase, propiedades y valores, cascada, herencia y contraste.
- **Práctica:** https://codepen.io/editor/Mateo-CB/pen/01a1ca70-6316-7fc1-af75-6dff41f17d91

### Lección 6. Espacios y tarjetas: el diseño también respira (7:48 min)

- **Descripción:** Compara una tarjeta cuyo texto toca el borde con otra que tiene espacio interior. Ajusta el relleno, la separación exterior y el ancho de la portada para que el contenido se lea con comodidad.
- **Enlace:** https://youtu.be/TRa0PpzIIu8
- **Consejos clave:** Modelo de caja, `padding`, `border`, `margin`, `box-sizing`, `max-width` y proporciones de una imagen.
- **Práctica:** https://codepen.io/editor/Mateo-CB/pen/01a1ca8f-fdfe-71f7-821d-65476b00581a

### Lección 7. Que funcione también en el celular (8:04 min)

- **Descripción:** Organiza las tarjetas en una columna cuando falta espacio y en tres cuando el ancho lo permite. Prueba también el menú con teclado, una vista estrecha y el zoom del navegador.
- **Enlace:** https://youtu.be/qWAcworIZB8
- **Consejos clave:** CSS Grid, Flexbox, `gap`, consultas de medios, ajuste de líneas y foco visible.
- **Práctica:** https://codepen.io/editor/Mateo-CB/pen/01a1ce0e-6b6f-7f44-9b47-0707e0410a97

### Lección 8. Prueba final: que se vea bien y funcione (7:36 min)

- **Descripción:** Revisa estructura, enlaces, imagen y presentación. Detecta y corrige tres fallos del proyecto, personaliza una recomendación y comprueba el resultado al abrir el Pen guardado.
- **Enlace:** https://youtu.be/FWpjIIbqm6Q
- **Consejos clave:** Depuración de propiedades, direcciones y clases; pruebas con teclado y diferentes anchos; entrega del proyecto.
- **Práctica:** https://codepen.io/editor/Mateo-CB/pen/01a1ceb0-3878-7f77-be4a-6d29399d059b
